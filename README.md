### Build the Profile PDF

The profile PDF is generated by merging the documents listed in `mergeConfig.json` (repo root):

```bash
pip install -r requirements.txt
python profil-builder.py
```

Each entry of `documents` is a path relative to the repo root (private documents can live in the local-only `.private/` folder) and accepts an optional 1-based page range `"pages": [min, max]`. The merged result is written to `output.name`, plus a dated copy when `output.datedCopy` is enabled. A custom config can be passed with `python profil-builder.py -c path/to/mergeConfig.json`.
